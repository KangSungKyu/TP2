# 🌌 TP2 전체 스테이지 (Stage 1~4) 아트 리소스 확장, Spine vs SpriteSheet 비교 및 AI 생성 도구 리서치 보고서

본 보고서는 TP2 메트로배니아 프로젝트의 범위를 **전체 4개 스테이지(Stage 1~4 풀 메트로배니아 스코프)**로 확장하고, 제작 비용을 극소화하기 위한 **애니메이션 구현 방식(Sprite Sheet vs Spine 2D) 비교** 및 **2D AI 생성 도구 워크플로우 분석**을 다룹니다.

---

## 1. ⚔️ 애니메이션 구현 방식 비교 및 최적안 선정 (Spine 2D vs Texture Sprite Sheet)

| 비교 항목 | 🖼️ Frame-by-Frame Sprite Sheet (전통 픽셀) | 🦴 Esoteric Spine 2D (뼈대 스파인 애니메이션) |
| :--- | :--- | :--- |
| **제작 메커니즘** | 모션의 모든 프레임을 개별 드로잉 (프레임당 단가) | 캐릭터 부위 컷팅 이미지 1장 ➔ 뼈대(Bone) & Mesh 스키닝 ➔ 키프레임 보간 |
| **전체 4개 스테이지 비용** | 몬스터 12종 x 40f = 480f ➔ **약 6,800만 ~ 8,200만원** | 원본 파츠 1회 컷팅 + 뼈대 리타겟팅(Re-target) ➔ **약 1,850만 ~ 2,400만원** |
| **비용 절감률** | 기준 비용 (100%) | **비용 약 70% 대폭 절감 (최저 예산 달성!)** |
| **AI 생성 기술 궁합** | AI로 픽셀 프레임 연속 생성 시 **프레임간 flickering(떨림) 및 형태 붕괴 심함** | AI로 **고품질 2D 컷팅 파츠 이미지 1장만 생성** 후 Spine 뼈대 매핑 ➔ **AI와 100% 최적 결합** |
| **유니티 메모리/용량** | 텍스처 아틀라스 수백 MB (메모리 과다) | JSON 뼈대 데이터 + 단일 파츠 Atlas 몇 MB (극경량화) |
| **모션 수정 & 착장 교체** | 무기/의상 교체 시 모든 프레임 재드로잉 (비용 과다) | Spine Attachment 슬롯만 교체 ➔ **실시간 무기 교체 0원** |
| **최종 판정** | ❌ 비추천 (비용 폭증, AI 생성 불가능) | **✅ 1순위 채택 (최저 비용 + 최고 AI 생산성)** |

> **💡 최종 채택 결론**: 
> 전체 4개 스테이지 확장 시 애니메이션 구현 방식은 **`Spine 2D (2D 뼈대 애니메이션)`**를 100% 채택합니다. 
> 이를 통해 전통 프레임 드로잉 대비 **제작 예산을 70% 이상 절감(약 5,000만원 이상 절약)**할 수 있으며, AI 생성 도구와의 완벽한 컷팅 파츠 연동이 가능해집니다.

## 🤖 2. 2D 아트 생성용 최신 AI 도구 리서치 & 워크플로우 (AI Tooling)

### 1) 🎨 파츠 컷팅 및 캐릭터/몬스터 전용 AI 도구
- **`Scenario.ai` (1순위 추천 - 게임 전용 파인튜닝 AI)**
  - **특징**: 프로젝트 전용 다크 판타지 픽셀 아트 스타일을 직접 학습(LoRA 파인튜닝) 가능.
  - **용도**: Stage 1~4 몬스터 12종, 보스 5종의 2D Side-View 컷팅용 부위 파츠(머리, 몸통, 팔, 다리, 무기) 세트 일관성 100% 생성.
- **`PixelLab / PixelVibe`**
  - **특징**: 2D 픽셀 아트 전문 AI 스프라이트 생성 도구.
  - **용도**: 알파 투명 배경 PNG 자동 생성, Palette 및 PPU 정밀 컨트롤, 몬스터 Base 픽셀 자산 제작.

### 2) 🏞️ 배경 패럴랙스 레이어 및 지형 타일셋 AI 도구
- **`Midjourney v6.1 / Niji v6`**
  - **특징**: 현존 최고의 2D 아트 렌더링 퀄리티.
  - **용도**: Stage 1~4 3층 패럴랙스 배경 레이어(Far Background, Mid-Ground, Near Atmospheric Fog) 및 시네마틱 컷인 생성.
- **`TileSetter AI / Luma AI`**
  - **특징**: 2D Seamless 지형 타일 매핑 생성 도구.
  - **용도**: 4개 스테이지별 고정 지형, 벽면, 1-Way 발판 seamless 타일 무한 생성.

### 3) ✂️ 픽셀 정리 및 파츠 분할 도구 (Post-Processing)
- **`Aseprite + AI Assistant Plugin`**
  - **특징**: 픽셀 아티스트의 표준 편집 도구에 AI 생성기 연동.
  - **용도**: AI가 생성한 이미지의 픽셀 노이즈 정돈(Pixel Cleaning) 및 Spine 뼈대 매핑용 파츠 분할(Layer Cutout).
