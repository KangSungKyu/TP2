## 1. 📊 애니메이션 구현 방식 비교: Texture Sprite Sheet vs Spine 2D Skeletal

메트로배니아 액션 게임의 대규모 제작 시 애니메이션 구현 방식에 따른 비용, 공수, 확장성 비교 분석 결과입니다.

| 비교 항목 | 🖼️ Texture Sprite Sheet (프레임 픽셀) | 🦴 Spine 2D Skeletal Animation (스파인 2D) |
| :--- | :--- | :--- |
| **작업 방식** | 매 프레임(Frame-by-Frame) 픽셀 아트 수동 그리기 | 1개 캐릭터 PSD 레이어 분리 ➔ 뼈대(Bone) 리깅 ➔ 메쉬 애니메이팅 |
| **프레임당 생산 비용** | 프레임당 **25,000원 ~ 45,000원** (모션 늘어날수록 비용 선형 증가) | 메인 뼈대 리깅 1회 설정 후 모션 추가 비용 **60~70% 절감** |
| **스테이지 확장성** | 새로운 몬스터/스킨 추가 시 매번 전 프레임 재그리기 필요 | **스킨 리스킨(Re-skinning) 기법 적용**: 1개 뼈대로 다른 몬스터 스킨 교체 가능 |
| **용량 및 메모리** | 텍스처 아틀라스 메가바이트(MB) 텍스처 용량 비대화 | 1개 스프라이트 시트 + 메쉬 뼈대 데이터로 **메모리 소모량 80% 감소** |
| **모션 튜닝/보정** | 애니메이션 속도/궤적 수정 시 전 프레임 수정 필요 | 유니티 타임라인/Spine 라이브 튜닝 및 보간(Interpolation)으로 **즉시 수정** |
| **최종 선택 및 결론** | **비추천 (대규모 스테이지 비용 폭발)** | **👑 (추천) Spine 2D 절감 방식 채택 (최소 55%~65% 예산 절감)** |

> **💡 결론**: 전체 스테이지(Stage 1~4)로 범위를 확장할 때, 몬스터/보스 캐릭터 유닛은 **Spine 2D Skeletal Animation** 방식을 채택하는 것이 초기 리깅비용 투자 대비 **전체 예산을 60% 이상 절감**하는 가장 경제적인 방식입니다.

## 🤖 3. 아트 리소스 생성을 위한 추천 AI 도구 및 파이프라인 리서치

생산 속도를 10배 이상 향상시키고 비용을 90% 이상 절감할 수 있는 최첨단 AI 생성 도구 파이프라인 리서치입니다.

### 🔮 1) 캐릭터 레이어 분리 및 Spine 2D 원화 생성 AI 도구

1. **Midjourney v6 / Niji 6 (일러스트/원화 시드 생성)**:
   - **용도**: 일러스트 퀄리티의 2D 픽셀 아트/다크 판타지 몬스터 및 보스 원화 콘셉트 디자이닝
   - **장점**: 업계 최고의 화풍 퀄리티 확보 (`--style raw`, `pixel art style, dark fantasy metroidvania side view`)
2. **Scenario.gg (게임 전용 AI 생성기)**:
   - **용도**: TP2 전용 아트 스타일 LoRA 학습 모델 생성
   - **장점**: 플레이어/몬스터 원화를 동일한 화풍 일관성으로 무제한 생성 가능
3. **Photoshop AI Generative Fill & Layer Splitter (Spine PSD 분리)**:
   - **용도**: 생성된 AI 원화에서 머리, 상체, 팔, 다리, 무기, 장식을 관절별로 2D 레이어 자동 분리하여 Spine 2D PSD 리깅용 파일 준비

### 🎞️ 2) Sprite Sheet / 픽셀 스프라이트 생성 AI 도구

1. **PixelLab API (픽셀 캐릭터/타일셋 전용 AI)**:
   - **용도**: `128x128` 2D Side-View 알파 투명 PNG 픽셀 스프라이트 자동 생성
   - **장점**: 배경이 투명하게 자동 정제된 PNG 스프라이트 즉시 획득
2. **Leonardo.ai (AI Sprite Sheet Generator)**:
   - **용도**: 4방향 픽셀 캐릭터 및 이펙트 파티클 스프라이트 시트 일괄 생성
3. **DeepMotion 2D / MonsterMash (AI 2D 포즈/애니메이션 생성)**:
   - **용도**: 비디오 포즈 추적(Motion Capture) 기반으로 Spine 2D 뼈대 애니메이션 키프레임 자동 추출
