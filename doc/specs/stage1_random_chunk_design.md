# Stage 1 무작위 청크 기획서

## 1. 목표

- 철위병 가론 전투 전에 패링·가드·회피·점프를 선택적으로 학습한다.
- 플레이어가 보스 직행, 안전 성장, 고위험 파밍을 직접 선택한다.
- Start와 Boss Gate만 고정하고 중간 청크는 시드 기반으로 구성한다.
- Stage 1 목표 플레이 시간은 `15–22분`, 보스 직행은 `6–10분`이다.

## 2. 기본 구조

| 항목 | 값 |
|---|---:|
| `StageData.idx` | `9001` |
| 배열 후보 | `3×4`, `4×3` |
| 활성 청크 | `9–11개` |
| Start | `ResourceData.idx 1040` |
| Boss Room | `ResourceData.idx 1042` |
| 보스 | `UnitBaseData.idx 3201` |
| Start–Boss Gate 최단 거리 | `3–4개` 연결 |
| 선택 분기 | 최소 `3개` |
| 순환 연결 | 최소 `1개` |
| 함정 배치 | `0개` (`ResourceData.idx 1070/1071` 사용 금지) |

```text
Start
├─ 빠른 경로 ───────────────── Boss Gate
├─ 안전 경로 ─ Combat ─ Rest ─ Boss Gate
└─ 성장 경로 ─ Combat ─ Reward ─ Elite ─ Boss Gate
                                           ↓
                                       Boss `3201`
```

Boss Gate는 방문 수, 처치 수, 빌드 점수로 잠그지 않는다. 전투 청크 내부 출구만 해당 청크 전투 종료까지 잠근다.

## 6. 전투 배치

### 위협 예산

| Boss Gate 최단 거리 기준 진행도 | Combat | Elite·Challenge |
|---|---:|---:|
| `0–33%` | `2–3` | 배치 금지 |
| `34–66%` | `3–4` | `5–6` |
| `67–100%` | `4–5` | `6–7` |

### 조합 예시

| 예산 | 구성 |
|---:|---|
| `2` | `3101×2`, `3102×1`, `3104×1`, `3105×1` |
| `3` | `3103×1`, `3106×1`, `3101×1+3102×1` |
| `4` | `3102×2`, `3104×1+3105×1`, `3101×1+3103×1` |
| `5` | `3102×1+3103×1`, `3104×1+3106×1` |
| `6` | `3103×1+3106×1`, Elite `3106×1+3102×1` |

- 활성 개체는 최대 `4`마리다.
- 동시 공격 권한은 최대 `2`개체다.
- 위협 비용 `3` 개체는 동시에 최대 `1`마리만 활성화한다.
- 지면 충격파는 `0.8초` 이내 중첩하지 않는다.
- 같은 조합은 한 런에서 최대 `2회` 사용한다.
- 일반 몬스터는 현재 청크의 SpawnArea 안에서만 추격·공격하며, Player 또는 Monster가 경계를 완전히 이탈하면 공격을 취소하고 생성 위치로 복귀한다.
- 복귀 중인 몬스터는 피해·공격·보상을 발생시키지 않으며 HP는 최대치, Posture는 `0`으로 초기화한다. Boss `3201`은 이 초기화에서 제외한다.

## 7. 보상과 선택

| 청크 | 보상 |
|---|---|
| Combat | 일반 축복 확률 `35%`, 런 재화 |
| Elite | 희귀 축복 `1개` 확정 |
| Reward | 축복 `3개 중 1개` |
| Rest | 최대 HP `30%`, 1회 |
| Event | 체력·재화·축복 교환 |
| Shop | 표시 상품 `3개`, 재고 고정 |
| Challenge | 강화 축복 또는 희귀 축복 |
| Treasure | 재화·소모품 |

Boss 직행에는 능력치 패널티를 주지 않는다. 방문 청크 `4개 이하`로 보스를 처치하면 기록·해금 가속 보상만 추가한다.

## 9. 완료 기준

- 보스 직행, 안전 성장, 고위험 파밍이 모두 가능한 그래프가 생성된다.
- 활성 청크의 평균 방문 목표는 `40–70%`다.
- 특정 전투나 보상이 Boss Gate 입장 조건이 되지 않는다.
- 보상 없는 막다른 길이 생성되지 않는다.
- 동일 시드에서 같은 배열·청크·몬스터 구성이 재현된다.
- 모든 Stage 1 시드에서 `hazardCount == 0`이며 함정 Spawn/배치 후보가 생성되지 않는다.
- 15 FPS에서도 일반 몬스터·소유 투사체가 SpawnArea 또는 이전 청크에 잔존하지 않는다.

### 🧠 [GameDesigner 자율 회고]
- 기획 무결성 비판: 신규 몬스터 3종과 청크 14종의 제작량이 Stage 1 MVP 범위를 늘릴 수 있으며, 원거리 탄환과 충격파 중첩은 15 FPS에서 회피 불가능한 조합을 만들 수 있다.
- 차기 방어 지침: 1차 구현은 신규 몬스터 `3104–3106` 중 2종과 청크 8종부터 검증하고, 투사체·충격파에는 전역 동시 공격 토큰과 최소 `0.8초` 간격을 적용한다.
