# 60x30 확장 테스트 스테이지 레이아웃 명세

## 📌 1. 개요 (Overview)
본 명세서는 `TP2` 프로젝트의 메트로배니아 이동 및 전투 테스트를 위해 구축된 **60x30 타일 규격 확장 멀티존 스테이지**의 구역 구성 및 설치 오브젝트 명세를 다룹니다.

---

## 🗺️ 2. 구역별 세부 구성 (Zone Breakdown)

```text
+-------------------------------------------------------------------------+
| [Zone B: 벽점프 멀티존]        | [Zone C: 전투/몬스터 아레나]             |
| - 수직 벽면 수련 구간          | - 보스(가론) 및 몬스터 전투 테스트       |
| - 1-Way Drop-Through 플랫폼    | - 이펙트 & 히트박스 시각화 검증          |
+--------------------------------+----------------------------------------+
| [Zone A: 2D 기본 이동 구간]                                             |
| - 평지 조작, 점프/대시/콤보 테스트 및 안전 스폰 구역                      |
+-------------------------------------------------------------------------+
```

### 2.1 Zone A: 기본 이동 구역 (Basic Movement Zone)
- **목적**: 2D 이동, 3타 콤보 공격, 기본 점프/대시 테스트 및 시작 스폰 지점
- **설치 요소**: 안전 지형 타일, 기본 장애물

### 2.2 Zone B: 벽점프 멀티존 (Wall Jump Multi-Zone)
- **목적**: 벽점프 0.18s 반동 궤적, 1-Way 플랫폼 하단 점프(Drop-Through) 검증
- **설치 요소**: `WallJumpSurface` 포함 수직 벽면, 1-Way 통과 발판 타일

### 2.3 Zone C: 전투 & 몬스터 아레나 (Combat Arena)
- **목적**: 유닛 피격, 몬스터 추적 AI(`ChaseTimeout`), 보스(철위병 가론) 및 VFX 이펙트 전투 테스트
- **설치 요소**: 몬스터 스폰 지점, 이펙트 시각화 존

## 4. 데이터 및 스폰 규칙

- 플레이어 마커는 기존 `Player.Instance`를 재배치하며 새 플레이어를 중복 생성하지 않는다.
- 몬스터·보스 마커의 `MonsterId`는 `UnitBaseData.idx`이며 `ResourceData.idx`까지 검증된 경우에만 스폰한다.
- 프리팹 로드 실패 시에만 이 레이아웃을 런타임 폴백으로 생성한다.
