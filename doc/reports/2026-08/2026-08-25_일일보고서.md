## ⚔️ 2. 피격·Guard/Parry 수선

| 공정 | 변경 | 결과 |
| :--- | :--- | :--- |
| 피격 표시 | `CombatStats` red flash 복원 | 피격 시각 피드백 회복 |
| Monster 공격 세대 | `actionGeneration`과 dedupe 수명주기 정리 | 독립 공격 간 상태 누수 차단 |
| Exterior pose | D1~D5 승인안 구현 | 기존 sweep 경로 재사용 |
| 근접 Body 피격 후 복구 | exterior pose/lock을 generation에 결속 | 이전 Body-first 잠금의 다음 공격 재사용 차단 |

승인된 Guard/Parry 핵심 계약:

1. Startup에서 경로를 시작하고 Active 진입 시 facing을 고정한다.
2. fraction이 작은 후보를 우선하며 epsilon 동률의 정면 공격만 `Parry > Guard > Body` 순으로 판정한다.
3. exterior history가 없으면 Body를 우선하고, 후면·비활성·방향 불일치는 Body로 처리한다.
4. moving attack은 Active 정지를 기본으로 하며 명시 데이터가 있는 경우만 이동한다.
5. face flip·teleport·generation 변경·cancel·death·groggy·pool 시 history를 폐기한다.

근접 Body 피격은 승인된 D2 결과로 허용하되, 이후 이격 상태에서 시작하는 독립 pattern/generation은 history를 새로 표본화한다. Monster의 exterior pose와 lock에 generation 표식을 추가해 비동기 종료와 다음 예약 경계에서 stale 상태가 전달되지 않도록 했다.

## 📦 5. Git·Unity 마감 상태

| 항목 | 보고서 발주 시점 상태 |
| :--- | :--- |
| Git commit/push/pull | 미수행 — CI 후속 |
