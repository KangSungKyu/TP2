## 🧩 3. UnitProjectile2D·native sweep 공통화

| 영역 | 변경 |
| :--- | :--- |
| 명칭 | `MonsterProjectile2D` → `UnitProjectile2D` |
| Unity 연결 | 기존 script `.meta` GUID와 Projectile `1045` Prefab/Resource 연결 보존 |
| Skill victim | Effect bounds의 native overlap/cast에 접촉한 적대 `UnitBase` 각각 1회 |
| Projectile victim | native sweep fraction이 가장 작은 적대 `UnitBase` 1개 |
| 제거 | 피해 지정을 위한 `Player.Instance`, `Monster.ActiveMonsters` 순회, hit-time `GetComponentInParent` |
| 공통 필터 | self/null/inactive/dead/동일 Faction/Neutral/stale owner generation 제외 |
| 반사 후 | 교체된 Owner·Faction·Generation으로 동일 판정 경로 재사용 |

명시적 target은 조준·이동 참고용으로만 남기고 실제 피해 권위에서는 제외했다. 별도 TargetManager·CombatManager·인터페이스·신규 테이블은 추가하지 않았다.
